# 營養衝衝跑 — 城市 3D 跑酷原型 2.0

遊戲場景使用原生 WebGL、JavaScript 和本地生成的低多邊形模型。鍵盤／觸控遊玩不需外部模型。新增的攝影機模式使用 Google MediaPipe Pose Landmarker，首次需要連網取得程式與模型。

## 遊玩

- 左右方向鍵或 A / D：換跑道。
- 空白鍵、向上方向鍵或 W：跳躍。落地後可再次跳躍。
- 向下方向鍵或 S：滑行約0.9秒；空中使用可快速落地並接滑行。
- P / Esc：暫停與繼續。
- 觸控裝置：畫面按鈕；也支援在跑道左右滑動換道、向上跳躍、向下滑行。
- 經典挑戰：90 秒、3 次碰撞機會。
- 輕鬆練習：90 秒、不扣碰撞機會。
- 食物 +10、閃避 +5、每連續收集10個食物 +20（碰撞歸零）、首次集滿六類 +50。經典模式完成90秒，剩餘每次機會額外 +10。
- 最佳紀錄依模式分開保存在目前瀏覽器中。儲存遭停用不影響遊玩。

## 城市跑酷規則

角色自動前進，30秒後與60秒後逐步加速。食物排列成連續路線；矮食物路障可跳過，糖飲橫桿可蹲下滑過，高點心列車必須換道。每個障礙組至少保留一條沒有障礙的地面跑道，長列車會以完整長度判定碰撞。

畫面採近距離背後視角、繽紛商店街與三條鐵道，場景和角色由本地幾何建立。攝影機左右移動對應絕對跑道、小跳對應跳躍；蹲下對應滑行並可維持低姿勢，空中蹲下則加速落地。辨識遺失、關閉相機時會清除持續蹲下輸入。

## 檔案

- `dist/index.html`：介面、食物集章、營養知識與結果。
- `dist/style.css`：桌面／手機／全螢幕版面。
- `dist/engine.js`：本地 WebGL 渲染、矩陣、光照、霧、立體幾何。
- `dist/core.js`：可獨立驗證的關卡、跳躍、碰撞與計分邏輯。
- `dist/game.js`：城市三跑道、角色、食物造型、操作與動畫。
- `tests/core.test.cjs`：關鍵遊戲規則驗證。
- `dist/pose-core.js`：玩家鎖定、2秒校正、鏡像換道、跳躍與蹲下判定。
- `dist/pose-worker.js`：在獨立 Worker 執行 MediaPipe 辨識。
- `dist/camera.js`、`dist/camera.css`：攝影機設定、骨架預覽、人物遮罩與離線準備。
- `dist/sw.js`：只快取遊戲檔案與固定版本 MediaPipe 資源，不快取攝影影像。
- `tests/pose.test.cjs`：合成骨架資料的控制邏輯測試；不代表真人辨識準確率測試。

將 `dist` 作為靜態網站根目錄即可執行。鍵盤／觸控所需檔案沒有遠端套件依賴；攝影機需要另外準備下述辨識資源。需支援 WebGL 的瀏覽器。

## 攝影機與離線使用

攝影機模式需要 HTTPS 或 localhost、使用者主動開啟相機並授權，及支援 Worker / OffscreenCanvas / WebAssembly 的瀏覽器。先讓全身雙腳入鏡，在中央站穩2秒。小跳為畫面座標動作推估；MediaPipe 的公尺世界座標以髖部中點為原點，不用來量整體離地高度。改變前後距離較多、追蹤失敗時需重新校正。

在展場電腦按「下載離線資源」，等待顯示完成。它會將遊戲、固定版本的 JS / WASM 與 Pose Lite 模型快取到目前瀏覽器；首次下載需要網路，儲存不可被清除。之後以同一瀏覽器和同一網址開啟。私人網站的登入頁不會被當成遊戲離線頁儲存。離線下載未完成不得宣稱可離線運作。若服務工作者被站台或瀏覽器限制，改將完整來源以 localhost 部署，並先完成資源準備。

模型與 WASM 來自官方模型儲存空間及 jsDelivr 的 @mediapipe/tasks-vision 0.10.14。影片只在裝置上處理，不上傳，不錄製。人物遮罩可關閉以減輕運算。

## 教學原則

積分為遊戲表現，不換算成真實體脂率。用均衡、多樣、份量與頻率說明食物選擇。角色外型不隨吃到食物或得分變胖變瘦。

內容參考：國民健康署「我的餐盤」、NIH NCATS「Fat (Adipose)」、NIDDK「Take Charge of Your Health: A Guide for Teenagers」。遊戲內營養小教室提供原始來源連結。
